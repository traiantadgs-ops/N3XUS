# N3XUS by TR0JAN

Инструмент для пентеста в Termux. Написан на Python, работает прямо с телефона.

## Возможности

- **1P L0GG3R** — ловит IP, страну, город и провайдера через Cloudflare Tunnel
- **С4ЙТ СК4НН3Р** — сканирует сайт на уязвимости (Nikto, WhatWeb, curl)

## Установка

Одна команда в Termux:
